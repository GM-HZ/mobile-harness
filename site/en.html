Capabilities

Working on your phone

Sessions & workspace

Chat, attachments, search and editing

Sessions and workspaces live in app storage on the device. Read and edit files with workspace tools, open generated files, and resume work in a saved session.

Local tools

Bash · Git · Python · JavaScript / TypeScript

The standard developer build bundles Alpine tools and runs commands on demand through PRoot. Summarize a CSV, inspect logs or check local Git changes. Programmatic tool calling (PTC) can run scripts and compose tool calls within the authorized scope.

Model connections

DeepSeek · compatible endpoints

Connect an account or configure an API key in the app. Online models need a network connection and receive the context needed for the task. An OpenAI-compatible endpoint was tested with Ollama in the emulator. Tool use depends on the selected model.

GitHub workflows

Forge · GitHub

In Forge-enabled builds, connect your GitHub account to read repositories and pull requests or make authorized changes. A private pull request workflow was verified with a real account.

Recovery & background work

Safe mode · HarmonyOS continuous tasks

If a plugin prevents the standard build from starting, safe mode lets you roll back plugin configuration. Background execution is off by default and asks for notification permission when enabled. HarmonyOS system policies still apply.

Builds

Choose a build

Standard developer build

Local sessions, a workspace and command-line tools. Use it for development and testing with Bash, Git, Python and PTC.

AppGallery candidate

A separate native distribution variant with privacy consent, image attachments and workspace search. General shell access, third-party plugin installation and remote connections are disabled in this variant.

Self / lab builds

Built from source for personal and lab testing, with optional native extensions signed at build time. Experimental remote access connects directly to a DSH host over HTTPS.

Experimental features & platform limits

How far along are sharing, voice and document features?

LiveShare has been verified using a self-hosted relay and a browser across two emulators. Device testing and the official public relay are pending. Voice, Office preview, optional LSP and pure JavaScript plugins have scoped tests. Support varies by build and device.

What are the limits of local commands and remote hosts?

Workspace file tools follow Harness permissions. OS-enforced workspace isolation, and arbitrary downloaded native programs face platform limits. Native extensions must be signed at build time. Interactive PTYs, containers and GUI automation are outside the current scope. SSH tunneling and reconnect behavior are still being verified.

What about Android and cloud execution?

The current candidate targets HarmonyOS. Android, cloud execution and broader cross-device continuity are on the roadmap.

Get started

Try the HarmonyOS candidate

On-device startup and tooling were verified on a Mate 60 with 0.4.69. Try 1.0.0 as a developer build while the AppGallery release is in validation.

  1. Prepare a package

    Use DevEco Studio 26, the pinned build inputs and the matching signing configuration. The ARM64 Phone emulator accepts an unsigned HAP. Physical devices require a suitable signed package.

  2. Connect a model

    Launch Mobile Harness and connect your DeepSeek account or configure a model API key in the app.

  3. Try a small task

    Add a file to the workspace, then ask the agent to find it, write a summary and save it. Open the session again to continue.
