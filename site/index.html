核心能力

手机上的工作方式

会话与工作区

对话、附件、搜索与编辑

会话和工作区保存在当前设备的应用空间。用文件工具读取和编辑资料、查看由模型生成的文件，并回到已有会话继续处理。

本机工具

Bash · Git · Python · JavaScript / TypeScript

普通开发包随包提供 Alpine 工具环境，由 PRoot 按需运行命令。适合统计 CSV、处理日志、检查本地 Git 改动。程序化工具调用（PTC）可在授权范围内运行脚本和组合工具调用。

模型连接

DeepSeek · 兼容端点

通过应用里的账号入口或 API Key 配置模型。在线模型需要联网，并接收回答任务所需的上下文。OpenAI 兼容端点已用 Ollama 在模拟器中验证，具体工具调用能力取决于所选模型。

GitHub 协作

Forge · GitHub

在支持 Forge 的构建中，连接 GitHub 后可读取仓库和 PR，并在授权范围内执行写操作。项目已用真实账号验证私有 PR 流程。

恢复与后台

安全模式 · HarmonyOS 长时任务

普通构建遇到插件启动故障时可进入安全模式，在恢复页回滚插件配置。后台长时任务默认关闭，开启后需要授予通知权限，运行仍受系统策略约束。

构建版本

按场景选择构建

普通开发包

本机会话、工作区和常用命令行工具。适合使用 Bash、Git、Python 与 PTC 的开发测试。

AppGallery 候选包

独立原生发行变体，包含隐私同意、图片附件和工作区搜索。通用 Shell、第三方插件安装和远程接入在此版本中关闭。

自建包 / 实验室包

供自编译和测试使用，可选构建期签名原生扩展。实验入口支持 HTTPS 直连远程 DSH 主机。

实验能力与平台边界

浏览器共享、语音和文档处理的验证进度如何？

LiveShare 已在自建中继和双模拟器浏览器链路验证，公网官方中继及真机链路待验。语音、Office 预览、可选 LSP 和纯 JS 插件均有分项验证，支持范围取决于构建和设备。

本机命令和远程主机有哪些限制？

工作区文件工具遵循 Harness 授权。系统级工作区沙箱、任意下载的原生程序仍受平台限制。动态扩展须在构建期签名。交互式 PTY、容器和图形界面自动化超出当前范围。SSH 隧道和断线续接还在验证。

Android 和云端执行什么时候可用？

本轮候选版面向 HarmonyOS。Android、云端执行和更完整的跨设备接续属于后续路线图。

开始使用

试用 HarmonyOS 候选版

0.4.69 的本机启动和工具链已在 Mate 60 上验证。1.0.0 可通过开发构建试用，AppGallery 正式发布仍待验收。

  1. 准备安装包

    使用 DevEco Studio 26、已锁定的构建输入和对应签名配置。ARM64 Phone 模拟器可使用未签名 HAP，真机需要适用的签名包。

  2. 配置模型

    启动 Mobile Harness，在应用里连接 DeepSeek 账号或配置模型 API Key。

  3. 跑一个小任务

    加入工作区资料，试着检索文件、写一份摘要并保存。重新打开会话，确认可以继续。
