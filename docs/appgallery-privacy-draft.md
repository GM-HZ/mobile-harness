# DSH-MH 隐私政策

草稿。发布前确认运营主体、联系渠道、实际开放的联网服务和生效日期。

**适用范围**　DSH-MH 的 HarmonyOS 手机应用，包名 `org.mobileharness.dshmh`。

**运营者**　［实际运营主体］

**联系方式**　［隐私事务联系邮箱］

**生效日期**　［发布日期］

## 首次启动

应用首次打开时会显示个人信息处理说明。在您同意后，应用才初始化本机工作区和会话服务。拒绝会退出应用。同意状态保存在应用的私有目录。您可以在「设置 → 通用 → 个人信息处理说明」重新查看。

## 本机保存的信息

- 为继续工作，应用在私有目录保存会话、工作区文件、用户主动导入的附件及应用偏好。
- 您配置的模型服务及访问凭据用于建立与相应服务的连接。应用将访问凭据保存在本地，并在对应服务需要认证时使用。
- 本机运行服务仅监听设备回环地址。浏览页面通过本机会话凭据访问该服务。
- 应用使用系统联网权限连接您使用的服务，使用网络状态权限获取建立连接所需的网络信息。

## 使用联网服务时

| 场景 | 接收方与处理内容 |
| --- | --- |
| DeepSeek 账号登录 | 您主动打开 DeepSeek 的登录页面，并在该页面完成验证。DSH-MH 使用授权结果连接服务。 [DeepSeek Harness 隐私政策](https://www.deepseek.com/harness/privacy/) |
| DeepSeek API Key | 应用把您提供的 API Key 用于向所配置的 DeepSeek 服务认证。推理请求可能包含提示词、会话上下文、附件以及任务所使用的工作区内容和工具结果。 [DeepSeek 隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html) |
| 自定义模型 | 若您添加自定义模型，您选定的模型服务会收到认证所需信息和生成回复所需的请求内容。具体保留期限、处理地点和权利行使渠道由所选服务说明。请在发送前查阅其隐私政策。 |
| 联网搜索或读取网页 | 当任务使用相应联网工具时，搜索服务会收到搜索词，目标网站会收到访问请求。请在任务中谨慎使用需要联网的数据。 |

上述接收方按照各自的政策处理所接收的信息。清除设备上的数据不会同步清除这些接收方已经取得的信息。

## 保留、删除与个人信息权利

应用将本地会话、工作区和设置保存在设备上，以便后续访问。您可在应用中管理会话或移除已配置的凭据，也可通过系统应用管理清除应用数据。清除应用数据会删除本机副本及同意记录，后续启动会再次显示隐私提示。卸载前可先保留需要继续使用的文件。

如需查阅、更正或删除个人信息，或对本政策提出疑问、投诉，可通过本政策列明的联系方式提交请求。由外部模型服务处理的信息，可按该服务的政策向其提交请求。

## 政策更新

如涉及个人信息处理方式的实质变化，运营者将在应用内告知，并按适用要求取得同意。
