# Mobile Harness 路线图

2026-11-08 整理。发布顺序为鸿蒙首发、云端与远端控制、安卓兼容。后续阶段以同一个任务在不同执行环境中的连续性为主线。

| 阶段 | 要交付的体验 | 验收 | 当前状态 |
| --- | --- | --- | --- |
| 1. 鸿蒙首发 | 在手机交代任务，由手机内的 Harness 执行。能管理会话、工作区、工具、审批和结果 | 真机首次启动、覆盖升级、重启恢复、真实任务与取消，保存制品和测试证据。启动目标为 60 秒以内 | 核心原型已通过 Mate 60 回归。0.4.24 强停重启 10.4 秒。该版本清空数据后的真机首次启动待测 |
| 2. 云端执行与远端控制 | 手机发起任务，将选定任务交给已绑定的电脑或云端工作环境。手机查看进度、审批、取消并接收结果 | 从手机到远端执行再到手机完成一次端到端任务。断网重连可追踪原任务，审批与取消准确关联，重试避免重复副作用 | 规划。已有云模型推理验证 |
| 3. 安卓兼容 | 安卓提供相同的任务入口，并适配本机工具和系统授权 | 在安卓真机运行本机任务及远端任务，按与鸿蒙相同的任务、审批和恢复契约验收 | 规划 |
| 长期演进 | 在授权下扩展 Browser Use、App 与系统操作，提供可持续记忆、可恢复的周期任务及主动服务 | 以真实任务完成率、用户介入次数、恢复成功率和资源开销衡量 | 愿景 |

## 鸿蒙首发前还要验证什么

- 在明确的真机环境补齐首次启动计时，记录峰值内存、资源展开和 Web 就绪时间。保留当前手机数据时可通过独立测试环境完成首次启动验证。
- 完成 DeepSeek 账号授权回调及模型读取图片内容的回归。附件上传与图片格式校验已有真机证据。
- 针对公网 Git 直连超时和 GIF 转换耗时保留基线。当前已通过临时代理验证公开仓库的浅克隆和文件校验。
- 系统交互 PTY 与 Phone Use 在当前首期范围内延期。Bash 的非交互工具、审批与作业已有实测。
