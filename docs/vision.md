# Mobile Harness 项目愿景

Mobile Harness 是面向 Mobile AGI 的执行底座。从手机接收用户意图，将它转成可执行、可恢复、可验证的任务。长期希望用户可以像委托一个了解自己的人一样交代任务，在设备变化后仍能接着做。

## 为什么从手机开始

手机是用户随身携带的入口，有语音、身份认证和通知能力。调度工具、管理会话及权限可以由手机上的 Harness 负责，推理根据成本、延迟、能力和隐私选择本地或云模型。能否在设备的电量、权限和后台运行约束下持续提供可靠服务，需要分别验证。

浏览器是覆盖面较广的执行环境。网页的 DOM 与结构化接口可以帮助自动化减少对图像识别的依赖。随着平台能力允许，再逐步连接手机 App、系统原生工具、API、MCP 和可扩展的 Skills。

## 长期产品形态

- **可委托**。用户用文字或语音交代目标，Agent 规划步骤、选工具、执行并核对结果。
- **可持续**。任务可暂停、恢复、取消和继续。长期记忆有来源，用户可以查看、更正、删除并控制使用范围。
- **可跨设备**。用户可以在手机发起任务，交给本机、电脑或云端执行，并从手机跟进和审批。任务需要本人确认时，等待授权并说明具体操作。
- **可扩展**。能力通过原生工具、浏览器、结构化接口、Skills 和插件扩展。敏感动作和新能力的授权可查看、可撤销。

## 如何衡量

看用户交代的任务有多少真正完成，过程需要介入多少次，设备离线或进程退出后能否恢复，以及结果能否独立核对。长时间执行与主动服务需要同时衡量授权准确性、电量、资源开销和跨设备的任务连续性。
