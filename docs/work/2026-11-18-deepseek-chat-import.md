# 鸿蒙 DeepSeek 会话导入

基线为 Mobile Harness 7c4dc8b、应用 0.4.38 和上游 RC.4。上轮交付跟随会话的标题与徽标技能，实际证据和代码已入远端。此次登记官方导入 bundle，通过 DSH 插件管理按需启用。

用独立工作区和合成的 v3 导出 ZIP 走正式上传。验证原时间、标题、分支选择、文本、思考与搜索记录、PNG 字节和无原件的文件卡片。分别验证匿名拒绝、坏档案、单条损坏跳过、上传取消后重新导入，以及插件停用与重启后存量会话继续。用随机标记检验真实模型从导入的文本历史取回上下文。

证据绑定安装制品和源码，原 profile、锁文件与测试凭据恢复。验收不需要访问真实用户的 DeepSeek 数据导出。

0.4.39 正式接口验收通过。合成 ZIP 有三条索引，写入两条有效会话并报告一条坏记录。历史包括原时间、用户固定标题、所选分支、搜索事件、原 PNG 与无原件的 PDF 卡片。匿名和不支持的请求被拒绝。并发上传遇到 busy，断开未上传完的请求后同一入口可再次使用。停用扩展并重启后，真实模型从导入的文本会话找回随机验证码。归档图片经重启再次读取，SHA-256 保持一致。

同一制品的 LSP 开关和故障恢复通过。原配置、锁文件和测试凭据恢复，夹具会话已归档，旧会话仍为 30 条事件。取消用例发生在上传阶段，保存过程中的取消另行验收。[准确制品与证据](../evidence/emulator-chat-import-0.4.39.json)

ArkWeb 的实际导入按钮、弹窗和原生文件选择器已通过触控与无障碍树核对，关闭插件后按钮消失。三次初始触控尝试和照片证据保留。启动时延迟出现的「开始使用」对话框拦住触控，一次超时诊断另有测试代码错误。临时配置测试凭据后重跑通过。文件选择器验证到打开，正式上传通过独立接口用例验证。
