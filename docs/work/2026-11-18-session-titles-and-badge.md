# 鸿蒙会话标题与徽标技能

基线为 Mobile Harness baed827、应用 0.4.37 和上游 RC.4。上次工作推动了工作树恢复、取消和随包扩展的正式入口，代码及证据已推送。此次通过同一入口登记官方会话标题和徽标技能，保留各自默认开关。

会话标题验收使用真实模型。核对首轮和后续人类消息的序号、生成来源及持久记录，人工固定标题后验证后续对话和重启。停用可选提供者后验证默认标题服务接管新会话。

徽标验收检查会话的技能目录、实际模型调用、随包 PNG 摘要及工作区 Markdown。通过官方接口关闭后再次检查目录。仅使用自建测试资料，结束后清理凭据和夹具并按字节恢复原配置。Forge 等既有目录与故障恢复按受影响范围回归。
