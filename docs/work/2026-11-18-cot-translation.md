# 鸿蒙思考内容翻译

基线是 0.4.44、DSH RC.5 和 Mobile Harness `56d2d63`。目标是把随包的官方思考内容翻译提供给 ArkWeb 用户。沿用上游插件管理、语言与提供者设置、显式启用和原文切换。翻译只在用户展开显示的内容后发起。

使用隔离模拟器与合成会话原文。通过官方设置和真实 ArkWeb 展开、切换原译文、切换匿名提供者、重启复用译文，以及失败时保留原文。用隔离的 HTTP 夹具核对请求形状、取消、持久化及无凭据转发。另用合成文本验证外部服务可用性。测试后移除配置和凭据。

保持其他插件、会话历史和默认权限。付费账号路由的完整授权与真机回归单独记录。

0.4.45 的 HAP 仅在 DSH 层的登记清单加入已随包的官方扩展。默认关闭。模拟器加载合成导入会话，真实 ArkWeb 展开、原译文切换、重启复用、失败重试及停用中止均通过。两种受控匿名请求均无授权或 Cookie，原会话事件按前缀逐条比较。会话激活允许新增 `session/end-seed` 事件，仅两条成功译文被保存。

真实 DeepSeek Flash 翻译使用临时测试 Key，仅提交合成的一条文本，请求记录确认关闭思考。真实匿名 Bing 与 Google 的请求都未完成。独立设备探针中 Bing 返回 HTTP 400 和 `Client Browser Version not supported`，Google 请求超时。保留官方默认选择，测试未转发用户会话或在失败后自动切换服务。两条公开端点仍待验。

同一 HAP 的 Inspector 面板与故障恢复通过，最终审计核对旧会话、原配置、默认权限和测试凭据移除。[实测记录](../evidence/emulator-cot-translation-0.4.45.json)
