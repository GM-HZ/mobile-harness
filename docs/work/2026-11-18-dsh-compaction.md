## 实测结果

- 默认普通包提供官方 /compact。空历史返回 No compactable history yet，错误参数返回 Usage 错误。真实模型压缩14个历史表面项，摘要替换节点3712字节；源日志的选中事件数据55871字节保留，不等同于同口径模型上下文大小。后台实际价格判定与 token 元数据见记录。手动压缩4.539秒，compactionId／commandId／sourceEventSeq配对，包含两组完整工具调用及结果。压缩后、同会话强停重开后，三个随机事实（包括被更正的端口）均精确回忆。
- 临时官方 bundle 扩展点监听 llm/stream，在真正的非空文本片段到达后才暂扣或抛错，不生成摘要。通过真实 HTTP socket 断开让请求取消，36毫秒观察到失败事务关闭；同时第二次 /compact 被拒。另一次流错误也没有提交成功摘要或检查点。两种场景随后都成功真实重试并准确回忆。
- 自动压力测试从 agentPresets/read 复制完整 standard 声明到独立临时预设，保留所有工具；只调整压缩阈值和保留预算，并将移动 YAML 后的 createRequire(baseUrl) 显式锚定同一已安装生产目录。实际步进压缩具有编号 turn，没有执行 /compact，真实摘要和回忆通过，总轮次4.799秒。测试后原预设及默认值恢复。不以低阈值测试冒充默认百万 token 压力或真实供应商 overflow 测试。
