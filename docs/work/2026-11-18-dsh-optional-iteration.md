# Ralph 与会话搜索的实际验收

目标：沿“全部 DSH 能力”清单验证随包但默认关闭的 Ralph 与 session-search。用标准 bundle 装配临时启用，不复制其实现，不永久改用户 profile；真实模型验证两轮 fresh-child、文件结果、取消／回收，以及持久会话的索引／事件读取与工作区授权。

基线：`035ba483d4d516a12501b518fc6794c4a34bdc0e`，现有 `codex/harmonyos-package-management`。普通 0.4.33 HAP 摘要 `8d5158a203cb1e9801b4976a6dca8534faa19de56ac25e289bd10ea6cf3a3035`，DSH npm／源码 RC.4，工作区干净。

非目标：不默认启用所有实验插件，不把 worker 自报 complete 当作独立验收；不使用主机替手机执行模型工具，不修改 Node、PTY、Phone Use 或降低审批。

验收：备份准确 manifest、锁文件与 boot；仅添加已有固定版本 bundle，测试完强停恢复并回读一致。Ralph 使用两阶段自有文件，要求两个不同、无父会话 seed 的真实子会话及可核验结果，验证取消时的实际子请求与 helper 回收。会话搜索使用自己创建的历史会话，强停重开后查找和读取准确事件，不接受仅有工具列表。记录准确命令、失败与最终状态，完成后提交远端。

状态：实施中。

已观察到两轮 Ralph 的真实 write／read／structured_output、两个不同且无父 seed 的子会话，文件字节一致；归档会话重启后五个 query 工具通过。Ralph 在真实 child request 期间取消，约150ms内父子回合中止且 helper 回收。首次跨工作区测试已返回正确拒绝，但夹具错误匹配其他措辞；改为锁定源码中的精确错误文案，错误结果、空搜索和私有内容不回传断言保留。
