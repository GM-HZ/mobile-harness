# 鸿蒙非交互持久 Bash

让 DSH 的 Minimal preset 复用官方持久 Bash 工具和按 agent 隔离的后端注册表。鸿蒙后端使用受管 Alpine Bash 进程与标准管道，完成后从该进程读取明确的状态边界。终端 UI 和系统 PTY 沿用原来的暂缓范围。

新路径须保留既有权限语义。没有可用沙箱时，持久 Bash 仅接受用户已明确选定完整文件权限的会话。普通会话保留默认工具和单次审批，已有持久会话须关闭后再切换权限。每条命令从空 stdin 执行，shell 的 cwd、环境和函数可以留到下一轮。取消、进程退出、agent 销毁和切换恢复模式均不复用旧 shell。

验收采用相同模拟器覆盖安装前后的 preset 清单、真实 DSH 工具调用、默认权限拒绝、两条会话互不共享状态、后台任务结果、取消后的进程回收和默认 Bash 回归。末尾校验制品、配置恢复与远端提交。

0.4.62 已完成上述管道工具、标准 Bash 工具链和文件工具验收，三个测试 shell 全部回收。切换权限模式时拒绝修改仍有活动 shell 的会话。测试结束恢复原 profile 并清除模型凭据。固定 DSH 版本为 npm `next` 的 `0.2.2-rc.5`。Mate 60 的 HDC USB 状态为离线。 [实测证据](../evidence/emulator-persistent-bash-0.4.62.json)
