# 第一可用版本（v1）计划：功能锁定 + 体验优化

日期：2026-11-21
基线：`main` @ 73591ce（合并 HarmonyOS 框架架构与稳定性工作）
原则：**功能锁定，只修质量**。本文件是冻结期的验收口径与优化清单。

## 1. 范围

- 功能：以 `docs/architecture/feature-roadmap.md` 的能力矩阵为准，**不新增能力**；
- 允许：bugfix、崩溃/兼容性修复、启动与运行性能、错误提示与恢复、设置/账号/首次使用体验、文档与发布工程；
- 不允许：新工具/新原生能力/新插件机制/新 UI 大改；确需新增时先解除冻结并更新本文件。

## 2. v1 验收口径（Definition of Done）

1. **可安装可启动**：store 签名包与 self 构建均可安装；冷启动成功率达到目标（真机 + 模拟器）；
2. **核心链路可用**：会话/模型对话、文件读写、bash/exec、动态库与原生扩展、插件安装与启用、
   Forge 只读；每个核心链路有 G2/G3 证据；
3. **崩溃可恢复**：坏插件/坏配置导致启动失败时，自动安全模式 + "回滚插件配置"可恢复；
4. **状态可见**：启动/等待/失败都有明确用户提示，不出现白屏/无限等待；
5. **数据安全**：凭据不落日志/证据；退出/重装不丢会话与工作区；
6. **回归门禁**：G0/G1/G2 nightly 全绿；G3 真机 verify/exec/overlay 全绿；G4 发布演练通过；
7. **发布材料**：版本记录、已知限制、安装/升级/恢复说明齐全。

## 3. 体验优化清单（P0 → P2）

| 优先级 | 事项 | 验收 |
| --- | --- | --- |
| P0 | 冷启动时间与首屏等待（解包/Host 启动/WebView 加载） | 真机冷启动 ≤ 目标值，有进度提示 |
| P0 | 启动失败恢复：安全模式入口、错误原因、重试 | 三类失败（Host 退出/超时/页面失败）都能自助恢复 |
| P0 | 插件回滚 UI E2E | 解锁后点击"回滚插件配置"可恢复并正常重启 |
| P0 | 首次使用：账号/权限/工作区引导 | 新安装用户 3 步内进入可用会话 |
| P1 | 错误提示统一（网络、模型、工具、权限） | 关键失败有可操作提示，不暴露堆栈 |
| P1 | 设置页信息架构（通用/账号/插件/恢复） | 入口可达、命名一致、无死路 |
| P1 | 大文件/长会话性能（内存、首屏渲染） | 不 OOM，滚动/输入无明显卡顿 |
| P1 | 通知/前台保活（任务进行中） | 后台切回不丢进度 |
| P2 | 视觉/文案一致性、深色模式 | 走查清单通过 |
| P2 | 反馈与日志导出（隐私脱敏） | 可导出诊断包，不含凭据 |

## 4. 流程

- 每个修复：分支 → G0/G1 → 相关 G2/G3 → 合并 `main` → `main` 回归；
- 每周汇总：`gate_report.py` 的 scoreboard + 本清单进度；
- v1 前冻结期结束条件：P0 全部关闭、G0–G3 全绿、G4 发布演练通过、已知限制文档完成。
