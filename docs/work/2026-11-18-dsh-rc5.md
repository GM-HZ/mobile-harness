# 鸿蒙 DSH RC.5 升级

基线为 Mobile Harness `cb5ba03`、0.4.41、DSH RC.4。目标是用同一官方 RC.5 版本的源码标签和 npm 生产依赖交付 0.4.42，保留原工作区、会话、权限、可选插件选择和恢复入口。上游本版改变网页搜索默认路由，按官方选择机制验证 DeepSeek 模型，不加手机专属搜索实现。

官方 tag `dsh-v0.2.2-rc.5` 指向 `9c2670d3bce5275e0d1610272958121af87787bb`。npm `next` 返回 `0.2.2-rc.5`。新锁校验全部官方 RC 组件，保持无关生产依赖原版本。构建继续核对原生字节、PTC bootstrap 和 HTTP 解析器的输入摘要。

验收先做 Phone 模拟器覆盖安装，确认实际装载 RC.5、匿名拒绝、原权限和 RC.3 会话保留。使用真实 DeepSeek 模型验证网页搜索及会话中的实际路由事件，复测 PTC、LSP、插件市场和故障恢复。疑点按具体受影响路径扩展；真机、其他模型供应商及待验可选能力沿用剩余验收清单。
