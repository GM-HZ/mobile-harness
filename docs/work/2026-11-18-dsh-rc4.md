来源：2026-11-18 官方 npm 的 `next` 为 `0.2.2-rc.4`；公开 GitHub 仅有 RC.3 源码发布标签。运行时以 npm 精确版本和完整性锁文件装配，源码子模块继续固定公开 RC.3 提交；不宣称该提交是 RC.4 源码。RC.4 的 CLI、PTC worker/provider、Workflow provider 和 MCP client 的 JS/TS 与 RC.3 字节相同；设置前端有变更。构建继续逐字节核对原生绑定。
