# 鸿蒙插件市场与更新回滚

基线为 Mobile Harness 9ba560f、应用 0.4.39 和 DSH RC.4。上轮交付 DeepSeek 会话导入及续接，已推送源码与实测证据。此次登记自带的官方插件市场，遵循其默认关闭策略。

在独立 Phone 模拟器用回环索引和 npm 仓库提供自建的纯 JS 包。经过官方 setIndexes、search、installBundle、listVersions、updateBundle 和 removeBundle，验收索引校验、分页、安装来源、依赖、启用状态、失败恢复与脚本策略。失败用例分别覆盖安装前拒绝和安装后激活异常，随后用真实工具断言旧版本重新可用。回滚不改用户的其他插件。使用独立夹具名，锁文件及配置恢复为原字节。

不向公共仓库发包。Git 来源升级、公共索引和市场长说明若未实测则保留在证据边界。
