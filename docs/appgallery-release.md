# DSH-MH AppGallery 首发

`1.0.0` 候选通过共同鸿蒙主线构建 AppGallery Release `.app`。构建和证据使用[发布手册](architecture/release-runbook.md)，下方保留历史 0.4.26 和 0.4.27 的验收及发布材料。

应用名称 DSH-MH，HarmonyOS 手机包名 `org.mobileharness.dshmh`，默认语言简体中文。后台当前关联 0.4.26（构建号 33），类目为「应用 / 工具」，主标签为 AI。开发者中心已有独立 APP ID，首发草稿已保存文案、鲸鱼图标、三张 1080×1920 竖屏截图，以及关联的云签名软件包。包合法性报告最终结果为「通过」，含一条随包源码文件提示。上架自检单独运行。草稿中已声明涉及 AI 文本生成并保存审核操作说明及模拟器显式标识截图。替换包已通过 Release 模式构建，版本为 0.4.27（构建号 34）。待正式链接确定后重新构建，再用 DevEco 云管理证书签名上传。

## 商店文案

**一句话简介**　手机上的 AI 工作区

**应用介绍**　DSH-MH 是面向 HarmonyOS 手机的 AI 工作区。在聊天中整理需求、阅读和编辑工作区文件，并在同一部设备上继续之前的会话。会话和工作区保存在本机。使用联网模型需要网络连接和对应的服务凭据，模型服务会处理生成回复所需的请求内容。

**审核说明**　首次启动可查看个人信息处理说明，拒绝后应用退出，同意后初始化本机工作区。登录入口支持 DeepSeek 账号和用户自行配置的 API Key。审核联网功能时需要可用的测试凭据。商店包关闭第三方插件安装、远程接入、通用终端、MCP 管理及会话日志下载。设置中的「通用」页可查看隐私说明或恢复运行时。Office 文件可作为工作区文件使用，商店版关闭 Office 转 PDF 预览。

## 模拟器验收

`1.0.0`（构建号 77）的 `3737f3a` 候选在 API 26 Phone 模拟器用 G4 未签名包完成全新安装。首次启动显示隐私提示，同意前 Host 未启动。拒绝后应用退出，重新打开再次提示。同意后 Host 正常就绪。`9b07d91` 候选保留测试同意记录覆盖安装，复验了图片附件及工作区搜索。v1 云签名包仍待真机验收。 [首次启动记录](evidence/device-lab/20261125-v1.0.0-3737f3a-appgallery-emulator.json) · [图片与搜索复验](evidence/device-lab/20261126-v1.0.0-9b07d91-appgallery-emulator.json)

使用 HarmonyOS Phone 模拟器（API 26）验证。三次正常模式强停重开均复用了全部运行时层，前台到 WebView 页面加载完成分别为 5.93、6.57、6.38 秒。本机 Host 对匿名请求返回 401，对认证请求返回 200。强停重开后验证原会话可读取，已写入的通用设置可再次读取。通用设置显示隐私说明及运行时恢复入口。插件安装、MCP 管理及终端创建的 RPC 均返回 404。

验收记录和上传素材保存在本机的 `.build/`。完整云签名 `.app` 通过 DevEco `verify-app` 和华为后台包合法性检测。将同一个 `.app` 安装到模拟器，三次正常模式强停重开分别为 4.74、6.66、5.37 秒。旧会话恢复、回环鉴权和受限 RPC 验证均通过。云签名 `.app` 的 SHA-256 为 `905ef1efcd08801a61fcc0cc2953c9d4a184e5c19fcc441e2529bd3ac6e26b6c`。使用模拟器本地测试模型完成一轮对话，真实聊天界面显示「AI 生成」。上线模型推理仍需另用有效服务凭据验收。

0.4.27 的隐私政策和源码下载地址可分别由构建参数注入。使用独立包名在同一模拟器验证「设置 → 通用 → 开源软件声明 → 获取对应源码」打开系统浏览器，加载配置的测试页面。正式发布包使用已确认的公开地址。

### Release 图片附件验收

已上传的 0.4.26 云签名包在 API 26 Phone 模拟器上拒绝有效 PNG。诊断日志显示系统拒绝 PRoot 的 `ptrace(TRACEME)`，图片解码进程未能启动。0.4.27 的商店配置改用 HarmonyOS Image Kit。独立 Release 测试包通过真实附件接口验收，普通 PNG 保留原尺寸，超过尺寸限制的无透明度和半透明 PNG 分别缩小并编码为 JPEG 和 WebP，损坏及截断 PNG 返回错误。

```sh
python3 tests/smoke/emulator-appgallery-images.py <loopback-target>
```

该命令适用于已在模拟器启动并同意隐私提示的候选包。准备送审的完整云签名包还需再跑同一回归。 [HarmonyOS Image Kit C 接口](https://developer.huawei.com/consumer/en/doc/harmonyos-references/capi-image-source-native-h/)

### Release 工作区搜索验收

0.4.26 云签名包的 `glob` 和 `grep` 均复现 ripgrep 进程启动失败。0.4.27 的商店配置在 Host 内运行 Rust 的 `ignore` 和 `regex`，保留 DSH 工具入口和结果格式。通过本机模型夹具在真实 DSH 会话中依次验证文件名匹配、带行号的内容匹配、排除 Git 目录、拒绝无效正则和拒绝工作区外路径。正式云签名包需再次执行相同回归。

```sh
python3 tests/smoke/emulator-appgallery-search.py <loopback-target>
```

原生搜索沿用 ripgrep 的 Rust 匹配组件，采用应用内文件遍历，测试范围覆盖上述工作区行为。

### 商店运行时精简

0.4.27 商店包使用鸿蒙原生 Node、Image Kit 和工作区搜索，启动只解压一份过滤后的 DSH 归档。包体从约 312 MiB 降至约 131 MiB，已检查 HAP 文件清单。应用数据仍使用原路径。在模拟器用相同包名从 0.4.26 覆盖安装后，图片和搜索回归通过。最终 131 MiB 候选包三次强停重开到页面加载完成分别为 6.05、4.41、4.42 秒，均复用本地 DSH 归档。已在 WebView 核对聊天界面和 0.4.27 模拟会话的「AI 生成」标识，截图存于本机发布产物目录。旧会话恢复、回环鉴权和受限 RPC 检查通过。普通调试构建继续提供 Alpine 运行时。商店版模拟器上的 DOCX 转 PDF 实测返回转换引擎不可用，已移除该引擎和对应预览注册，保留工作区文件访问及其他文档预览。


## 隐私政策草稿

已整理 [隐私政策草稿](appgallery-privacy-draft.md) 和 [用户协议草稿](appgallery-terms-draft.md)。生效日期和发布主体以定稿为准。公开链接和应用内说明应同步维护。

- **应用运营及联系**　填写 DSH-MH 的实际运营主体、隐私联系邮箱、用户请求的处理方式及期限。
- **本地数据**　同意记录、会话、工作区文件、所选模型和连接配置保存在应用的私有存储中，以恢复会话和继续任务。在应用中可以管理会话，也可以通过清除应用数据或卸载删除本地副本。清除本机数据不会删除模型服务已接收的数据。
- **联网请求**　应用通过系统联网权限连接模型和所选服务，通过网络状态权限获取用于建立连接的网络配置。使用联网模型时，应用将生成回复所需的提示词、会话上下文、附件和任务中使用的工作区内容或工具结果发送至选定服务。联网搜索或读取网页会向所选搜索服务或目标站点发送相应请求。
- **身份及凭据**　用户主动选择 DeepSeek 登录时在其登录页面认证，应用使用授权结果连接服务。使用 API Key 时，应用将其用于对应服务的身份认证。模型服务按照其自身政策处理收到的信息。按首发支持的服务填写准确的处理主体、用途、信息种类和政策链接。
- **用户权利**　补齐访问、更正、删除、撤回同意和投诉的具体渠道。需要清除当前设备上的同意和本地数据时，可在系统应用管理中清除数据。
