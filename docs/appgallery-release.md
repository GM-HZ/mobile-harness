# DSH-MH AppGallery 首发

应用名称 DSH-MH，HarmonyOS 手机包名 `org.mobileharness.dshmh`，默认语言简体中文。首发候选版本为 0.4.26（构建号 33），类目为「应用 / 工具」，主标签为 AI。开发者中心已有独立 APP ID，首发草稿已保存文案、鲸鱼图标、三张 1080×1920 竖屏截图，以及关联的云签名软件包。包合法性显示「已达标」。

## 商店文案

**一句话简介**　手机上的 AI 工作区

**应用介绍**　DSH-MH 是面向 HarmonyOS 手机的 AI 工作区。在聊天中整理需求、阅读和编辑工作区文件，并在同一部设备上继续之前的会话。会话和工作区保存在本机。使用联网模型需要网络连接和对应的服务凭据，模型服务会处理生成回复所需的请求内容。

**审核说明**　首次启动可查看个人信息处理说明，拒绝后应用退出，同意后初始化本机工作区。登录入口支持 DeepSeek 账号和用户自行配置的 API Key。审核联网功能时需要可用的测试凭据。商店包关闭第三方插件安装、远程接入、通用终端、MCP 管理及会话日志下载。设置中的「通用」页可查看隐私说明或恢复运行时。

## 模拟器验收

使用 HarmonyOS Phone 模拟器（API 26）验证。三次正常模式强停重开均复用了全部运行时层，前台到 WebView 页面加载完成分别为 5.93、6.57、6.38 秒。本机 Host 对匿名请求返回 401，对认证请求返回 200。强停重开后验证原会话可读取，已写入的通用设置可再次读取。通用设置显示隐私说明及运行时恢复入口。插件安装、MCP 管理及终端创建的 RPC 均返回 404。

验收记录和上传素材保存在本机的 `.build/`。本次使用未签名 HAP 验证模拟器，DevEco 云签名 .app 已通过后台包合法性检测。实际模型推理需另用有效服务凭据验收。

## 隐私政策草稿

生效日期和发布主体以定稿为准。公开链接和应用内说明应同步维护。

- **应用运营及联系**　填写 DSH-MH 的实际运营主体、隐私联系邮箱、用户请求的处理方式及期限。
- **本地数据**　同意记录、会话、工作区文件、所选模型和连接配置保存在应用的私有存储中，以恢复会话和继续任务。在应用中可以管理会话，也可以通过清除应用数据或卸载删除本地副本。清除本机数据不会删除模型服务已接收的数据。
- **联网请求**　应用通过系统联网权限连接模型和所选服务，通过网络状态权限获取用于建立连接的网络配置。使用联网模型时，应用将生成回复所需的提示词、会话上下文、附件和任务中使用的工作区内容或工具结果发送至选定服务。联网搜索或读取网页会向所选搜索服务或目标站点发送相应请求。
- **身份及凭据**　用户主动选择 DeepSeek 登录时在其登录页面认证，应用使用授权结果连接服务。使用 API Key 时，应用将其用于对应服务的身份认证。模型服务按照其自身政策处理收到的信息。按首发支持的服务填写准确的处理主体、用途、信息种类和政策链接。
- **用户权利**　补齐访问、更正、删除、撤回同意和投诉的具体渠道。需要清除当前设备上的同意和本地数据时，可在系统应用管理中清除数据。
