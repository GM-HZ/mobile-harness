# Gates

`gates/registry.json` is generated by `scripts/adaptation/registry.py` and lists
the gate tiers. The plan is described in
[`docs/architecture/2026-11-20-adaptation-and-gates-plan.md`](../docs/architecture/2026-11-20-adaptation-and-gates-plan.md).

- **G0** static/consistency (fast, every change)
- **G1** host contracts (P1)
- **G2** emulator capability (nightly / pre-merge)
- **G3** real-device lab (device online / release)
- **G4** build/release variants (pre-release / daily dry run)
