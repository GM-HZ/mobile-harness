# Gates

`gates/registry.json` is generated by `scripts/adaptation/registry.py`; the plan is
in [`docs/architecture/2026-11-20-adaptation-and-gates-plan.md`](../docs/architecture/2026-11-20-adaptation-and-gates-plan.md).

```sh
python3 gates/run.py --list                  # show tiers and commands
python3 gates/run.py --tier G0               # static/consistency (fast, every change)
python3 gates/run.py --tier G1               # host contracts + upstream anchors
python3 gates/run.py --tier G2 --only capability-parity-gate
python3 gates/run.py --tier G2,G3            # lab tiers (needs emulators/device)
```

Entries with `<placeholders>` are skipped and recorded; exit code 2 from a tool
means "environment unavailable" and is recorded as a skip as well.

Evidence: `docs/evidence/gates/<tier>/<commit>.json` locally; CI uploads
`gate-evidence-pr` / `gate-evidence-nightly` artifacts.

| Tier | Scope | Where |
| --- | --- | --- |
| G0 | static/consistency: manifest, pins, submodules, host-only checks | any machine |
| G1 | host contracts: syntax of overlays, literal upstream anchors | needs assembled DSH layer for anchors |
| G2 | emulator capability: consolidated 10-step gate + ad-hoc smoke suites | self-hosted macOS lab |
| G3 | real-device lab: Mate 60 verify/exec/overlay probes | USB device online |
| G4 | build/release variants: store/self builds + store-shape assertions | build machine |
